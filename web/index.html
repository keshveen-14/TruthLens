    How it works

    A retrieval-augmented answer pipeline with a hallucination detector on the end. Every claim in an answer is checked before anyone relies on it.

    Sample documents describe a fictional product. In the browser engine the answer writer is a demo that plants false sentences on purpose, and the checker is the lexical baseline from the Python pipeline.
